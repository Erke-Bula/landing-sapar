# PawCare Veterinary Clinic

A responsive veterinary clinic website created for Laboratory Works 2 and 3.

## Project Description

PawCare Veterinary Clinic is a responsive website for a modern veterinary clinic.

The website provides information about veterinary services, the clinic, veterinary specialists, and contact information.

The project was created using semantic HTML5, Sass (SCSS), Flexbox, CSS Grid, and BEM methodology.

## Responsive

The website is responsive and works on different screen sizes.

* **375px** — mobile phone
* **768px** — tablet
* **1280px** — desktop

Screenshots of the responsive design are stored in the `screenshots` folder.

## Why this tool

Sass was used to make the CSS code easier to organize and maintain. Variables were used for colors, sizes, shadows, and other repeated values. Mixins were created for responsive media queries. Nesting was used to make related styles easier to read. BEM naming was used to organize HTML and CSS classes. The project uses Flexbox and CSS Grid to create responsive layouts. Sass was compiled into `style.css` because GitHub Pages does not compile SCSS automatically.

## BEM Methodology

The project uses the BEM naming methodology.

Examples:

* `.header`
* `.header__container`
* `.header__logo`
* `.header__nav`
* `.service-card`
* `.service-card__title`
* `.button--primary`

This makes the CSS structure clear and easier to maintain.

## Sass Features

The project uses:

* Sass variables
* Sass mixins
* Sass nesting
* BEM class naming
* Responsive media queries

The main Sass file is `style.scss`, and the compiled CSS file is `style.css`.

## Responsive Breakpoints

The website uses three main screen sizes:

* **Mobile:** up to 599px
* **Tablet:** 600px–1023px
* **Desktop:** 1024px and above

The layout changes automatically depending on the screen width.
